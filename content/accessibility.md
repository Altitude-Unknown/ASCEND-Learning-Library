## An open library

You do not need an account to use this site. Pages, navigation, and resource records work without JavaScript. Search and interactive filters need JavaScript.

## Accessibility

This prototype is designed toward WCAG 2.2 AA principles, including keyboard navigation, visible focus, descriptive links, semantic headings, and responsive layouts. This is a design goal, not a claim of audited conformance.

Use the “Skip to main content” link at the start of each page to bypass repeated navigation. Every tab-accessible control has a visible focus indicator. Text can be enlarged using browser zoom.

Video records include space for captions and transcripts. Captions, alternative text, accessible documents, keyboard behavior, and screen-reader usability must be reviewed when real resources are published. The project’s accessibility contact will be added before public launch.

## Privacy

There are no accounts, analytics scripts, advertising trackers, or embedded videos loaded by default. If a published video offers a “Load video” button, choosing it connects to YouTube’s privacy-enhanced embed service. External resources have their own privacy practices. The hosting provider may process ordinary web request logs.

## Using materials

Each resource will state its own author, version, and license where supplied. A license is not implied by its appearance in this library. Current resources are prototype records; they do not include real downloadable materials.
