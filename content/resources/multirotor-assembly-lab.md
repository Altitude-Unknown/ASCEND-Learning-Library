## About this activity

**Goal:** make precise electrical connections with various soldering techniques, install motors and propellers with the proper direction and pitch, and install and align flight controllers.

**Procedure:** using the materials provided, assemble the motors, ESC, and flight controller using proper soldering techniques. Check the motor spin direction, then install the correct propellers in the correct locations. Determine the proper alignment for the flight controller.

Read [the flight controller stack sections of Chapter 5](/build-multirotor/textbook/building-a-multirotor-aircraft/#flight-controller-stacks-and-selection) first. To connect to Betaflight and check the spin direction, follow [Connect your aircraft to Betaflight](/build-multirotor/textbook/building-a-multirotor-aircraft/#connect-your-aircraft-to-betaflight) and [Checking the motor direction](/build-multirotor/textbook/building-a-multirotor-aircraft/#checking-the-motor-direction-in-betaflight).

<p class="notice"><strong>Propellers go on last</strong>Check the motor directions with the propellers removed. Install the propellers only after every motor spins the right way.</p>
