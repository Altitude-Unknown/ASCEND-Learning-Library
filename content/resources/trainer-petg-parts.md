## About these files

Ten supplied files for motor mounting, wing supports and clips, a control horn, and tail clips.

- **V-tail clips:** `empanage-clip-v-tail.stl` (30°), `Empannage-clip-v-tail-45.stl` (45°), and `Empannage-clip-v-tail-45-foam.stl` (45°, foam tail).

Editable versions are in the [Fusion part designs](/resources/trainer-fusion-parts/).

These downloads preserve the original file contents and filenames. Visit the [aircraft project page](/uas/trainer-airplane/) for the related components.
